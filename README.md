# Open Feynman-Path Molecular Nanotechnology — a Get Physics Done (GPD) project

An open-science, **Get Physics Done (GPD)**-formatted repository for the *Feynman-Path pursuit*:
the molecular-manipulator / mechanosynthesis program toward atomically precise construction, and
its machine-verifiable physics. Maintained by the **Nano Dynamics Institute (NDI)**, a 501(c)(3)
non-profit, as a contribution to the molecular-nanotechnology research commons.

GPD: a Formulate -> Plan -> Execute -> Verify workflow for analytical/numerical physics
(`github.com/psi-oss/get-physics-done`).

## Layout (GPD agent-repo conventions)
```
GPD/            seed artifacts the GPD agent ingests (PROJECT, REQUIREMENTS, ROADMAP, STATE, config)
knowledge/      source corpus: framework + prize docs, and the Feynman-Path V&V data
AGENTS.md       operating instructions for any agent acting on this repo
GPD-INGEST.md   how to map this repo into a GPD runtime
METHODOLOGY.md  the verifiable-task method and verification targets
```

## What's here
| Path | What it is |
|------|------------|
| `knowledge/feynman-prize-reframed.pdf` | Material-agnostic, tiered reframing of the Feynman Grand Prize (proposal for discussion). |
| `knowledge/mnt-capability-axes-and-characterization.pdf` | The eight capability axes + characterization protocol for productive nanosystems. |
| `knowledge/feynman-prize-verifiable-task-schema.pdf` | The prize restated as numeric targets and decomposed into machine-verifiable tasks. |
| `knowledge/program_tasks_feynman_path.csv` | Machine-readable Feynman-Path task list (`id, segment, vtype, track, tool/method, title, acceptance`). |
| `knowledge/vv_matrix_feynman_path.xlsx` | The Feynman-Path V&V matrix (acceptance predicates, verification types, TRL, dependencies). |
| `GPD/` | NDI-authored GPD seed artifacts. |

## Status (do not distort)
Early-stage (**TRL 1-3**). The science pieces are demonstrated in the cited literature; the
integrated system is not built. Acceptance "PASS" means model-consistency, not empirical proof.

## Scope
This repository contains **only open Feynman-path science and plans**. It contains **no commercial /
application-specific designs, economics, or go-to-market material**.
